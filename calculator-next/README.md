# Neon Calculator

Ein schoener Taschenrechner mit HTML, CSS, React und Next.js.

## Features

- Modernes Neon- und Glassmorphism-Design
- Grundrechenarten: Plus, Minus, Mal, Geteilt
- Prozentfunktion
- Vorzeichen wechseln
- Responsive Layout fuer Handy und Desktop
- Klare Projektstruktur im Ordner calculator-next

## Starten

1. In den Projektordner wechseln: cd calculator-next
2. Abhaengigkeiten installieren: npm install
3. Development Server starten: npm run dev
4. Im Browser oeffnen: http://localhost:3000
